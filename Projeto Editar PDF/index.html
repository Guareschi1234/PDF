Junte vários PDFs, organize páginas ou extraia páginas para criar um novo arquivo.

Clique ou arraste arquivos PDF para adicioná-los

Adicione dois ou mais PDFs. Arraste os arquivos para ordenar documentos e arraste as miniaturas (ou use as setas) para ordenar páginas.

Pré-visualização do PDF unido

Adicione pelo menos dois PDFs para ver e organizar as páginas na ordem final.
📄

Clique ou arraste um arquivo PDF para esta área

Sem divisão, as páginas selecionadas serão baixadas em um único PDF.
